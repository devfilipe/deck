# #13 — The exercises do not teach ask, bundle, metrics, pack review, board template or couples

**open** · docs · opened 2026-09-06

---

**As** someone learning deck from the exercises
**so that** what I learn is the tool as it is, not as it was.

Repository: `deck`

`deck-exercises` was written before `deck ask`, `deck bundle`, `deck metrics`, `deck pack review`, `deck board template`, scopes, `couples:` and `deck toggle set --why` existed. Nothing in it is now wrong — one broken flag was fixed — but a reader finishes both exercises without meeting the merge-readiness bundle, the consultation record, or the second kind of edge.

This is a writing job with a design choice in it: extend the polyglot exercise, or add a third that starts from a workspace that already works and exercises what happens around a delivery.

### Acceptance
- [ ] a learner meets `bundle` and reads one for a task they finished
- [ ] a learner records a consultation and resolves it
- [ ] a learner declares a coupling and sees what it changes and what it does not
- [ ] every command an exercise names is checked against the current binary
