# Code of conduct

## The short version

Be someone others want to work with. Disagree about the work, not about the
person doing it.

## In practice

- **Argue from evidence.** "This breaks when X" beats "this is wrong". If you
  can reproduce it, say how; a reproduction is worth more than an adjective.
- **Assume the other person had a reason.** Most odd-looking code was a fix for
  something. Ask what, before proposing to remove it.
- **Take correction plainly.** Being wrong in public is the normal cost of
  working in public. Own it, fix it, move on — no ceremony either way.
- **Do not make it personal**, and do not make it about identity, background or
  anything other than the work.

Harassment, insults, and deliberate disruption are not welcome, and neither is
the sort of relentless nitpicking that is technically about the code and plainly
about the person.

## If something goes wrong

Contact the maintainer at the address on the commits. Reports are handled
privately. The maintainer may edit, hide or delete comments, close issues and
block accounts, and will say when they have.

This project is small enough that this is one person's judgement, applied
carefully. That is worth stating rather than dressing up as a process.
